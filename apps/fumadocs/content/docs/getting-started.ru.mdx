Эта страница описывает минимальные команды для установки зависимостей, запуска
приложений и проверки целостности репозитория.

## Установка зависимостей

Запустите команду из корня репозитория:

```bash
pnpm i
```

## Запуск разработки

Запустите web-приложение и docs одновременно:

```bash
pnpm dev
```

При запуске поднимаются:

- `apps/web`
- `apps/fumadocs`

## Генерация артефактов

Если вы обновляете контракты или API, перегенерируйте артефакты:

```bash
pnpm gen
```

Эта команда выполняет:

- `pnpm gen:ui` для схем и manifest UI Kit
- `pnpm gen:api` для typed API клиента

## Запуск тестов

Контрактные тесты валидируют states UI Kit по схемам:

```bash
pnpm test
```

## Полный гейт

Перед открытием PR запустите полный чек:

```bash
pnpm check
```

Команда включает генерацию, тесты и no-drift проверки.
