## Описание

Двоичный контрол для выбора элементов в списках и таблицах.
Когда использовать: для независимых включений и выключений в списке опций.
Когда не использовать: если требуется выбрать только один вариант (используйте
radio или select).
Граница неотмеченного чекбокса использует `--ui-color-border-control` для
согласованности с Figma-экранами авторизации и таблицами.
Размер по умолчанию — `sm` (22px). Используйте `md` (24px) только при явном
требовании.

## API

Props определены в контракте UI Kit. Ключевые props: `checked`, `label`,
`children`, `disabled`, `size`.

**Спецификация**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`checkbox.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/checkbox.schema.json)
