## Description

Compact pagination element used in navigation controls.
When to use: for paginated navigation controls where page indices are visible.
When not to use: for infinite scrolling or when page numbers are hidden.

## API

Props are defined in the UI Kit contract. Key props: `value`, `selected`, `disabled`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`page-number.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/page-number.schema.json)
