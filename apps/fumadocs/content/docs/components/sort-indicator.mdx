## Description

Visual indicator showing the current sort direction (ascending or descending) in table headers. Supports three states: no sort, ascending, and descending.

## API

Props are defined in the UI Kit contract. Key props: `direction`, `size`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`sort-indicator.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/sort-indicator.schema.json)
