## Description

Composable input field for auth/forms with optional label, error message, and password support.
Default auth-field baseline follows Figma metrics: `55px` height, `12px` radius, and border token `--ui-color-icon-muted`.

## API

Props are defined in the UI Kit contract. Key props: `label`, `value`, `type`, `error`, `startAdornment`, `endAdornment`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`input.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/input.schema.json)
