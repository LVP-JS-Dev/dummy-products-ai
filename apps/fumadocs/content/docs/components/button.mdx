## Description

Primary action trigger used for creating or confirming actions.
When to use: for primary or high-confidence actions that should stand out.
When not to use: for passive navigation or destructive actions without confirmation.

## API

Props are defined in the UI Kit contract. Key props: `text`, `showIcon`, `iconName`, `badgeLabel`, `badgeCount`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
