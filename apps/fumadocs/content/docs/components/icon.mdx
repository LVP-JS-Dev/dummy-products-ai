## Description

Icon component that renders the SVG glyphs from the Aiti Guru design set.
When to use: to reinforce meaning or aid scanning alongside text labels.
When not to use: as the only indicator for critical actions without text or aria-labels.

## API

Props are defined in the UI Kit contract. Key props: `name`, `size`, `color`, `title`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`icon.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/icon.schema.json)
