## Описание

Используйте для краткой обратной связи и статусов операций.

## API

Props определены в контракте UI Kit. Ключевые props:
`title`, `description`, `tone`, `dismissible`, `actionLabel`.

**Спецификация**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`toast.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/toast.schema.json)

## Примеры

<div style={{ display: "grid", gap: 12, maxWidth: 420 }}>
  {Object.entries(states.toast).map(([name, props]) => (
    <div key={name} style={{ display: "grid", gap: 4 }}>
      <Toast {...props} />
      <span>{name}</span>
    </div>
  ))}
</div>
