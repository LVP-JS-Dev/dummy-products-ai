## Description

Binary control for item selection within lists or tables.
When to use: for independent on/off choices in a list of options.
When not to use: when only one option should be selected (use radio or select).
Unchecked checkbox stroke uses `--ui-color-border-control` for Figma auth/table consistency.

## API

Props are defined in the UI Kit contract. Key props: `checked`, `label`, `children`, `disabled`.
