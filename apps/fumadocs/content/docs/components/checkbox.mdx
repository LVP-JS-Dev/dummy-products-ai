## Description

Binary control for item selection within lists or tables.

## API

Props are defined in the UI Kit contract. Key props: `checked`, `label`, `disabled`.

<div style={{ display: "grid", gap: 12 }}>

      <Checkbox {...props} />
      <span>{name}</span>
    </div>
  ))}
</div>
