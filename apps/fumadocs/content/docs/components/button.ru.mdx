## Описание

Основной триггер действия для создания или подтверждения операций.
Когда использовать: для первичных или уверенных действий, которые должны
выделяться.
Когда не использовать: для пассивной навигации или деструктивных действий без
подтверждения.

## API

Props определены в контракте UI Kit. Ключевые props: `text`, `children`,
`showIcon`, `iconName`, `badgeLabel`, `badgeCount`, `size`, `variant`.
Поддерживаемые варианты включают `blue` (основная градиентная заливка с
обводкой `--ui-color-primary-border`), `secondary` (белая заливка с тонкой
границей) и `icon` (прозрачная иконка без текста).

**Спецификация**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`button.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/button.schema.json)
