## Описание

Адаптивный компонент изображения с поддержкой `alt` и декоративного режима,
настройками загрузки и fallback-источником.

## API

Props определены в контракте UI Kit. Ключевые props: `src`, `alt`,
`decorative`, `width`, `height`, `fallbackSrc`, `loading`, `decoding`,
`fetchPriority`, `objectFit`, `objectPosition`, `aspectRatio`.

**Спецификация**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`image.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/image.schema.json)

## Примеры

<div style={{ display: "grid", gap: 12 }}>
  {Object.entries(states.image).map(([name, props]) => (
    <div key={name} style={{ display: "grid", gap: 6 }}>
      <Image {...props} />
      <span>{name}</span>
    </div>
  ))}
</div>
