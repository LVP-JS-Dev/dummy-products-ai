## Description

Text field optimized for search queries with distinct inactive, active, and disabled states.
When to use: for free-text search across lists, tables, or content pages.
When not to use: for structured filtering where predefined options are required.

## API

Props are defined in the UI Kit contract. Key props: `placeholder`, `state`, `showIcon`, `value`.
