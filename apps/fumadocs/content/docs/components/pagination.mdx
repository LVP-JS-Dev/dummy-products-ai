## Description

Navigation component for paged content, including previous/next actions and numbered pages.
Number pills default to `30x30` with active accent fill and compact `6px` inter-button spacing for table-footer parity.

## API

Props are defined in the UI Kit contract. Key props: `currentPage`, `totalPages`, `maxVisiblePages`, `disabled`.

- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
