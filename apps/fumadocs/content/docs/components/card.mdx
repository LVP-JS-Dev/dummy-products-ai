## Description

Base wrapper for structured blocks like login forms, summaries, and modal content.
The default outlined style is tuned for auth-screen parity (dual gradient fill/stroke shell with `40/34` outer-inner radii).

## API

Props are defined in the UI Kit contract. Key props: `size`, `outlined`, `elevated`, `title`, `description`.

**Specification**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`card.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/card.schema.json)
