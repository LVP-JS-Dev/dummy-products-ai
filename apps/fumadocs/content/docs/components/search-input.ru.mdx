## Описание

Поле ввода, оптимизированное для поиска, с состояниями inactive, active и
disabled.
Когда использовать: для текстового поиска по спискам, таблицам или контенту.
Когда не использовать: для фильтров с заранее заданными опциями.
Базовая геометрия соответствует Figma: высота `48px`, радиус `8px`, цвет
placeholder и иконки берется из `--ui-color-text-placeholder`.

## API

Props определены в контракте UI Kit. Ключевые props: `placeholder`, `state`,
`showIcon`, `value`, `ariaLabel`.

`ariaLabel` — основной источник для `aria-label`. Если его нет, компонент
использует `placeholder` как fallback.
