## Описание

Навигационный компонент для постраничного контента с действиями назад и вперед и
номерами страниц. Пилюли имеют размер `30x30` с активной акцентной заливкой и
компактным интервалом `6px` для паритета с футером таблицы.

## API

Props определены в контракте UI Kit. Ключевые props: `currentPage`,
`totalPages`, `maxVisiblePages`, `disabled`.

**Спецификация**
- [`manifest.json`](https://raw.githubusercontent.com/lvpjsdev/dummy-products/main/packages/ui-kit/src/generated/manifest.json)
- [`pagination.schema.json`](https://raw.githubusercontent.com/lvpjsdev/dummy-products/main/packages/ui-kit/src/generated/schemas/pagination.schema.json)
