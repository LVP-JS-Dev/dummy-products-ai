## Описание

Визуальный индикатор, показывающий текущее направление сортировки (по возрастанию или убыванию) в заголовках таблиц. Поддерживает три состояния: без сортировки, по возрастанию и по убыванию.

## API

Props определены в контракте UI Kit. Ключевые props: `direction`, `size`.

**Спецификация**
- [`manifest.json`](../../../../../packages/ui-kit/src/generated/manifest.json)
- [`sort-indicator.schema.json`](../../../../../packages/ui-kit/src/generated/schemas/sort-indicator.schema.json)

## Примеры

<div style={{ display: "flex", gap: 24, alignItems: "center" }}>
  {Object.entries(states.sortIndicator).map(([name, props]) => (
    <div key={name} style={{ display: "grid", justifyItems: "center", gap: 4 }}>
      <SortIndicator {...props} size={14} />
      <span>{name}</span>
    </div>
  ))}
</div>
