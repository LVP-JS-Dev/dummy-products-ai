Эта страница дает краткое описание системы, ее результатов и ролей ключевых
частей.

## Назначение

Монорепозиторий показывает contract-first UI систему, которая одинаково полезна
для людей и для машин. UI Kit остается источником истины, а docs и приложения
потребляют его.

Проект используется как:

- портфолио-пример архитектурного уровня
- база для agent-first UI разработки
- продуктовая демо-сцена с реальными сценариями

## Что означает contract-first

Каждый компонент имеет формальный контракт, который описывает shape props. Типы
и states выводятся из контрактов и экспортируются как публичный API.

Это дает:

- единый источник истины для API компонентов
- сериализуемые states для docs, тестов и инструментов
- сгенерированные схемы и manifest для агентов и тулов

## Кто что потребляет

UI Kit определяет API, остальные части используют его через публичные экспорты:

- `apps/web` рендерит продуктовые сценарии через UI Kit
- `apps/fumadocs` документирует компоненты и использует states UI Kit
- `packages/gen-api` независим и отвечает за API клиент

## Где лежат требования

Требования разделены по зонам ответственности. Используйте эти файлы как
источник истины:

- `PRD.md` для системных целей и инвариантов
- `packages/ui-kit/PRD.md` для контрактов, states и генерации
- `apps/fumadocs/PRD.md` для документации
- `apps/web/PRD.md` для продуктовых требований
