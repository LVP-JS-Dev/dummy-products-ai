## UI Kit Tokens

UI Kit components rely on CSS tokens. Import the token stylesheet once in your app's global CSS:

```css
@import "@dummy-products/ui-kit/tokens.css";
```

Browse the full token reference:

- [Design Tokens](/docs/design-tokens)
