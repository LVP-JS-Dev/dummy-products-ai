# TanStack Table Migration Proposal

## Why

Текущая таблица товаров не имеет зафиксированной табличной основы, из-за чего сортировка, рендер колонок и расширяемость ведут себя неоднородно между состояниями списка и поиска. Сейчас нужно стандартизировать таблицу на TanStack Table, чтобы стабилизировать поведение и упростить дальнейшее развитие функциональности.

## What Changes

- Перевести рендер таблицы товаров на TanStack Table в `apps/web`.
- Зафиксировать единые column definitions и управляемое состояние сортировки/пагинации в табличном слое.
- Сохранить текущие пользовательские требования (колонки, сортировка, пагинация, подсветка рейтинга), но закрепить их через единый table engine.
- Уточнить контракт для таблицы в products-каталоге, чтобы список и результаты поиска использовали одну и ту же табличную модель.

## Capabilities

### New Capabilities
- `web-products-tanstack-table`: Использование TanStack Table как обязательного табличного движка для экрана товаров.

### Modified Capabilities
- `web-products-catalog`: Уточнение требований к реализации таблицы товаров через TanStack Table при сохранении текущего пользовательского поведения.

## Impact

- `apps/web`: экран товаров, конфигурация колонок, логика сортировки/пагинации и интеграция списка/поиска.
- Зависимости: подключение/использование `@tanstack/react-table`.
- Тесты: обновление unit/integration проверок для таблицы и сортировок.
- Документация change/spec: добавление новой capability и дельты для `web-products-catalog`.
