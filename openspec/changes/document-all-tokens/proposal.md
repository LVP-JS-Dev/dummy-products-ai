# Why

Сейчас в документации Fumadocs фактически нет справочника по дизайн‑токенам: видно только, что токены подключаются через CSS. Это усложняет использование UI Kit, приводит к догадкам/копированию из кода и увеличивает риск рассинхронизации (какие токены считаются публичными, как они называются и что означают).

## What Changes

- Добавить в документацию UI Kit страницу (или раздел) “Design tokens / Дизайн‑токены” со списком **всех публичных токенов**, сгруппированных по категориям: **цвета**, **типографика**, **отступы/spacing**, **скругления/radius** (и др. при наличии).
- Для каждого токена зафиксировать: имя CSS‑переменной, текущее значение, краткое назначение/семантику и пример использования через `var(--token)`.
- Обеспечить, что справочник отражает “source of truth” (CSS token surface UI Kit) и не расходится с фактическим набором токенов.
- Обновить навигацию/индекс документации, чтобы страница токенов была легко доступна.

### Modified Capabilities

- `tokens-css-usage`: уточнить требования к “documented CSS token surface” — документация должна включать полный референс всех публичных CSS‑токенов, разбитый на группы (цвета/типографика/spacing/radius/и т.д.), с назначениями и примерами.

## Impact

- Docs: `apps/fumadocs/content/docs/` (новая страница/раздел токенов, обновление индекса/навигации).
- UI Kit token surface: `packages/ui-kit/src/tokens.css` и/или `packages/ui-kit/src/Tokens.ts` как источник списка токенов; потребуется убедиться, что документация соответствует актуальному набору.
